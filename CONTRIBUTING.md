# Contributing

Thank you for helping build the KTU M.Tech CSE Resource Hub.

## The simple rule

This site is **static** and **file-driven**. There is no database and no backend.

To add a resource:

1. Fork this repository (or clone and start your own — see below).
2. Place your file under `public/academiadrive/`, organized by semester / subject / category.
3. Use descriptive filenames, e.g. `Computer_Networks_Unit_1_Notes.pdf`.
4. Run `npm run compress` (optional) and `npm run build` to verify.
5. Open a pull request.

## If this repository is inactive

If maintainers are unresponsive, you are welcome to **clone this repo and start your own**. The structure, build, and deployment are fully self-contained: fork it, change the `basePath`/remote, and deploy to your own GitHub Pages. No permission needed.

## Guidelines

- Be relevant to KTU M.Tech CSE.
- Follow the suggested folder structure in the README.
- Avoid duplicates.
- Respect copyright; provide attribution.
- Keep filenames clear and consistent.
